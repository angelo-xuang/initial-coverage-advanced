# 阶段 1：公司研究

产物：`[公司]_公司研究_[日期].md`，6000–9000 字。这是后面四个阶段的素材库，也是研报正文一、二、三章的底稿。

公司研究不是把资料分门别类地罗列，而是按投资逻辑链组织——读完这一稿，应该能回答三个问题：这是一家什么公司、它所在的赛道有多大、它凭什么占据这块市场空间。每一节都为后面的投资论点服务。

开始前先确认标的所在市场：在 A 股、港股还是美股，决定了披露平台（巨潮资讯网 / 港交所披露易 / SEC EDGAR）、会计准则和币种。

## 开工先查内部知识库（Step 0：先用轮子，避免从零重复）

正式外部采集之前，**先把已有的内部材料捞出来当底料和锚**——前提是本环境登记了「知识/研究检索层」（见 skill 目录 `data-sources.md`）。**没登记 / 没装知识库就跳过本节、直接进取数，不停、不问、不报错**（纯非破坏性）。

登记了研报知识库（如 `investment-knowledge-base`）时，查两样：

1. **"我已知什么"** —— 从自有定性研究里定位这家公司 / 同行 / 产业链的既有笔记、过往拆解，作为理解业务、选锚的起点。
2. **"街上怎么说"** —— 从卖方研报库里定位覆盖这家公司的投行研报，带出处捞共识口径（增速 / 毛利 / 目标价 / 评级理由）。这是阶段 4「vs 卖方共识对标表」的底料。

怎么用结果：

- 命中的材料作后续采集的**起点与交叉验证源**，不从白纸开始；已有结论 / 数字一律**标出处**（哪份笔记、哪家投行哪期研报），写进研究稿「数据来源」。
- 知识库只做"定位 + 带源取数"，**不做质量打分、不保证时效**——拿到后自行判断新旧，按时效性补最新一手数据（最新年报 / 季报、近两季电话会）。**铁律：数字只认带出处的卖方研报 / 公司披露，自有定性研究只供选锚理解、不抄数。**
- **命中为空也正常**（库里暂无这家）——直接进取数做全新研究。

## 取数

四类数据，每类对应独立检索：

| 类别 | 主来源 |
|------|--------|
| 公司基本面 | 年报/中报/季报、招股书、公司公告、公司 IR 页 |
| 业务与经营 | 财报的分部数据、业绩说明会纪要、公司官网产品页 |
| 行业与竞争 | 行业研究机构（IDC、Counterpoint、艾瑞、灼识）、协会数据、竞品财报 |
| 市场数据 | 股价、市值、股本、一致预期（当次检索，带日期） |

信任分级和双源印证按 SKILL.md 的取数标准执行。每个进稿的关键数字记下来源和日期，关键数据（基年分部收入、行业规模、市占率）要双源。

### 结构化加速层 + 档位记账

开工前先看 skill 目录有没有 `data-sources.md`（结构化加速层登记表，机制见 SKILL.md「执行标准-取数」）：有就按它登记的源优先取上表对应字段，没有就按上表主来源直接取。无论哪种，**建模关键字段（基年分部收入、客户集中度、财年口径）回一手披露原文对账**——加速层省时间，不降权威底线。

给每个关键数标它走了哪一档（加速层 / 一手披露 / 联网），汇成研究稿末尾一张「关键数据档位与来源」附表：

| 数据点 | 取值 | 档位 | 具体来源 | 日期 |
|---|---|---|---|---|
| 2024 分部收入（XX 业务） | XX 亿元 | 一手披露 | 2024 年报 P.XX | YYYY-MM-DD |
| 行业规模（2029E） | XX 亿元 | 联网 | IDC 报告 | YYYY-MM-DD |

这张表是过程记账，留在研究稿，**不进阶段 5 的 DOCX**（DOCX 只保留读者向的来源行）。

### 派子 agent 取数

阶段 1 常 fan out 子 agent 分头查公司基本面 / 行业空间 / 竞争格局。给子 agent 的 prompt 必须把取数契约**原样带下去**，否则子 agent 会按自己默认（多半直接联网）取数、绕过加速层和一手披露底线。子 agent 任务模板：

> 任务：查 [公司] 的 [基本面 / 行业空间 / 竞争格局]。
> 取数规则：① 先看 skill 目录 `data-sources.md` 有无数据/知识加速层，有则优先用结构化源取行情 / 三表 / 一致预期，用研报知识库取"街上怎么说 + 自有研究"；② 建模关键字段（分部收入 / 客户集中度 / 财年口径 / 三表关键项）必须回一手披露原文（巨潮 / 披露易 / EDGAR）对账，不可只用加速层或联网；③ 软数据（行业规模 / 市占率 / 竞争格局）可大规模并行联网广搜；④ 每个关键数标来源、日期、走了哪一档（加速层 / 知识库 / 一手披露 / 联网）；⑤ 关键数据双源互证。
> 产出：[字段清单] + 每个数的来源 / 日期 / 档位。
>
> **取一手披露的操作提醒**：SEC EDGAR / 公司 IR 的 PDF 常对 WebFetch 返回 403（反爬）。改用带合规 UA 的代理 curl 下载，再本地解析：`curl -s --proxy 127.0.0.1:7890 -A "研报研究 <你的邮箱>" -o filing.pdf "<url>"` → `pdftotext -layout filing.pdf -`。SEC submissions 索引：`https://data.sec.gov/submissions/CIK<10位补零>.json`（外国发行人看 20-F / 6-K，不是 10-K）。

## 写什么

### 点题设问（供摘要开头，不单独成引言段）

写一句点题设问，抛出这家公司最值得研究的那个问题。看标杆：中泰-腾讯用"为何腾讯的产品总能后来居上""为何日赚 5 亿仍能大象起舞"这种设问当钩子。这句是切入点，不是公司简介。

注意：报告**不写独立的"引言"段**。这句设问移到报告摘要的开头当钩子（见 `assets/报告模板与版式.md`），阶段 5 组装时正文直接从"一、公司概况"起。这里产出这句，是为摘要开头备料。

### 一、公司概况

**历史复盘**。沿革按阶段分（不是流水账），每个阶段点出战略转折和它对今天的意义。配一张历史沿革图（时间轴 + 关键节点 + 收入规模）。上市公司再做一段**股价复盘**——把历史股价和重大事件、政策、业绩拐点对齐，看清股价对什么敏感。这段为后面"为什么是现在"做铺垫。

**业务布局**。核心动作是**分部拆分**，但拆之前先给每条业务线一段**本体**。读者人设是**懂金融、但不一定懂这个细分行业的专业投资者**——不是科普对象，也不是行业老兵。每条业务线按统一骨架写，三条线同骨架、可比性强：

1. **本体：这业务是什么 + 在投资上为什么重要**。重心是讲清它的**战略定位**（如"纯代工、不与客户争利"），不是科普通用名词。
   - **通用专业词直接用、不展开**（晶圆代工、先进制程、毛利率这种专业读者都懂的，点到即止）。
   - **只有真正冷门 / 前沿、一般读者大概率不知道的名词**（如 CoWoS、chiplet、某种特殊材料），才简单提一句讲懂，必要时配**一个克制的比喻**（≤1，且只在一句精确话讲不清时用）。
   - register 走**专业 + 精炼**，靠"精确机制"讲透（如"晶体管密度→性能功耗→单位价值→门槛→少数厂商"），**不堆生活比喻**。
2. **怎么变现 + 公司当前位置**——收入、占比、增速、变现模式、产品矩阵 / 产能 / 份额。
3. **末尾一张业务横向对比表**——各业务线的收入 / 占比 / 增速 / 毛利 / 变现模式横向并排，一眼看清财务特征差异（这直接决定阶段 2 模型按单线还是分部建）。

ICA 章节是拆开的：业务的"本体 + 变现"放 1.2，"壁垒 / 份额深挖"留三、竞争壁垒，"下游作用 / 行业空间"留二、行业空间——别在 1.2 把壁垒和空间也讲了，会和后面重复。配分部收入图、分部毛利率图。

示例骨架（单一主业按制程节点拆的晶圆代工，专业 register、零生活比喻）：

> **业务布局——专精先进制程的纯代工厂，先进节点是利润与定价权的来源**
>
> **晶圆代工。** 台积电是纯晶圆代工厂（pure-play foundry）：只按客户（苹果、英伟达、AMD）的设计图纸制造芯片，自身不做设计、不出自有品牌产品。这个"不与客户争利"的定位，是它能同时绑定几乎所有无晶圆厂设计公司的结构性前提——客户不必担心把设计交给一个潜在竞争对手。
>
> **先进制程为什么是命脉。** 制程节点（3nm/5nm/7nm）代表晶体管密度，数字越小、性能功耗越优、单位晶圆售价越高；越先进的节点研发与资本开支门槛越高，能跟上的厂商越少。台积电先进制程（7nm 及以下）占晶圆收入 74% 且持续提升，这是它定价权与高毛利的来源。
>
> **收入结构与当前位置。** 按节点：3nm 25% / 5nm 36% / 7nm 13%；按平台：HPC 61% / 智能手机 26%。需求重心正从手机转向 AI——HPC 占比一年内从约 55% 升至 61%。

示例里"晶圆代工 / 先进制程"是通用词，直接用、不解释；真遇到 CoWoS 这种冷门词，才补一句"把多颗芯片拼装在同一基板上的先进封装，绕开单芯片面积上限"。单一主业可收缩（本体 + 变现两段即可）；多业务公司每条线套同骨架，末尾必有横向对比表。

**股权与治理**。股权结构、实控人、一致行动人、重要股东背景（有没有国资/产业资本）、组织架构。配股权结构图。

**管理层**。核心高管 3–5 人，每人讲背景、履历、任职年限、关键成就。技术驱动的公司重点讲核心技术团队的学术和产业背景。

**财务分析**。历史收入、利润、毛利率、费用率、现金流、ROE 的趋势，判断公司处在什么阶段（高增长 / 成熟 / 拐点）。点出财务上的关键特征，比如腾讯的"EPS 增速 > 净利润增速 > 毛利润增速 > 收入增速"高质量增长范式，或寒武纪的"营收阶梯式增长 + 盈利端扭亏转盈"拐点。

### 二、行业空间

把公司放到行业背景中考察。市场规模（带来源、年份、预测 CAGR）、增长驱动、产业链位置、政策环境。多业务公司按分部分别讲空间（腾讯拆成 2C 的"现金牛"和 2B 的"魔法盒"）。

行业规模数要权威来源（IDC、灼识、Wind、协会），标清是历史值还是预测值。配市场规模图、产业链图。

### 三、竞争格局

谁在与它竞争、它处在什么位置。5–10 家可比公司，给具体数据（市占率、营收、关键经营指标）做横向对比，不是罗列名字。配市占率图、竞品对标表。点出公司的差异化优势——这是后面"竞争壁垒"章的素材。

### 风险

8–12 条，分类列（宏观/行业、经营、政策监管、技术/竞争、财务/估值）。每条写清触发条件和影响，不要笼统。

## 自检

- 开工查过内部知识库（若本环境登记了）：已有研究 / 卖方共识当了底料、都标了出处；没登记则跳过、做全新研究
- 三个核心问题（什么公司 / 多大空间 / 凭什么）都答上了
- 分部拆分到位，为阶段 2 的模型结构铺好了
- 行业规模、市占率有权威来源和年份
- 每个关键数有来源和日期，关键数据双源
- 全文按 `研报写作规范.md` 写，无 AI 味
